# Discussions

Multi-agent design discussions about this repo, run with the
[agent-roundtable](https://github.com/deepwatrcreatur/agent-roundtable)
protocol: every voice answers the same prompt through its real CLI or API,
marks each question `[satisfied]`, `[satisfied-conditional: X]` or
`[needs more evidence: X]`, and the IC fact-checks disagreements and runs a
narrowed follow-up when needed. Raw answers are kept in each file's appendix.

Router-specific discussions live in
[nix-router-optimized `docs/discussions/`](https://github.com/deepwatrcreatur/nix-router-optimized/tree/main/docs/discussions).
